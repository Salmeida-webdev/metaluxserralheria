# Metalux Serralheria

Landing page premium desenvolvida para a Metalux Serralheria, empresa especializada em portões, grades, corrimãos, coberturas, estruturas metálicas e esquadrias sob medida em Mauá-SP.

O projeto foi construído com foco em:

- visual agência 10/10;
- performance premium;
- carregamento rápido;
- responsividade real;
- UX refinada;
- conversão;
- branding forte;
- aparência profissional de empresa real.
